# Золотой ковш — сайт и панель администратора

Статический сайт GitHub Pages + Supabase (Postgres, Auth, Storage).

## Настройка
1. Создать отдельный Supabase project для этого сайта (не использовать базу другого бизнеса).
2. В SQL Editor выполнить весь файл supabase/setup.sql.
3. В Authentication → Users создать пользователя администратора.
4. Скопировать UUID пользователя и выполнить SQL: insert into public.admin_users(user_id) values ('UUID_ПОЛЬЗОВАТЕЛЯ');
5. В настройках проекта взять Project URL и publishable key (или legacy anon key) и заполнить config.js. Никогда не вставлять service_role/secret key в браузер.
6. В GitHub Settings → Pages выбрать Deploy from branch → main → /(root).
7. Открыть /admin.html и войти. Добавляйте фотографии и удаляйте их через панель.
8. Форма сайта создаёт заявку в booking_requests; без настроенного Supabase отправляет готовое сообщение в WhatsApp.

## Доступ и безопасность
- Посетители могут читать только активный контент и отправлять заявки.
- Администратор может управлять материалами и читать заявки.
- Файлы хранятся в публичном bucket kovsh-media; загрузка и удаление ограничены RLS-политиками для admin_users.
- В браузере разрешён только publishable/anon key. Секретный service_role key не использовать.
